- **Frontend**: React 18/19, TypeScript, Vite, CSS Modules.

- **Architecture**: Microservices-oriented design principles (FastAPI, LangGraph, AWS, Azure).

## 📦 Getting Started

### Prerequisites
- Node.js (v18+)
- npm or yarn

### Installation
1. Clone the repository:
   ```bash
   git clone git@github.com:Shubhamdutta2000/Shubham-Dutta-Portfolio.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```
